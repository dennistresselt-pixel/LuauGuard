# Security policy

LuauGuard is a best-effort static-analysis utility, not a replacement for secure architecture, code review, Roblox platform controls, or runtime testing.

For a defect that could create a security risk, avoid publishing exploit details or real secrets in a public issue. Contact the repository maintainer privately through a contact method on their GitHub profile, if available. Include the affected version, a minimal synthetic reproduction, expected behavior, and observed behavior. Never include real credentials.

If a secret was committed, treat it as exposed and revoke or rotate it immediately. Deleting it from the latest commit alone may not remove it from Git history.
